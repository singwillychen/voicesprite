LOCAL ENGINE

本地開源引擎安裝與連線

在你自己的電腦安裝開源語音模型 GPT-SoVITS，再用 VoiceSprite 橋接程式連到網站。中文音色最接近本人，有 NVIDIA 顯示卡時速度接近即時。

運作方式

VoiceSprite 網站送出文字＋你的參考錄音
→
橋接程式你的電腦・port 9881
→
GPT-SoVITS你的電腦・port 9880

所有運算都在你的電腦上，聲音不會上傳到任何伺服器。只有開著啟動檔的那台電腦能使用本地引擎。

需要的設備

最佳Windows 10／11 ＋ NVIDIA 顯示卡（RTX 系列，顯示記憶體 6 GB 以上）：速度接近即時
可以用Mac（Apple M 系列晶片）或沒有 NVIDIA 顯示卡的電腦：可以執行，但每句要等比較久
硬碟空間Windows 約 25 GB（整合包約 8 GB，解壓後更大）；Mac 至少 15 GB
記憶體建議 16 GB 以上
瀏覽器電腦版 Chrome 或 Edge（Safari 可能擋下本機連線）

步驟一：安裝 GPT-SoVITS

  1. 下載官方整合包（已包含 Python 與所有套件，不用另外安裝）。
    到 官方整合包下載區 ↗，建議下載 GPT-SoVITS-v2pro-20250604.7z（約 8.2 GB）。顯示卡是 RTX 50 系列的話，改下載檔名有 -nvidia50 的版本。
    官方說明：GPT-SoVITS README 的 Windows 段落 ↗
  2. 解壓縮：.7z 檔需要用 7-Zip ↗（免費）解壓。解壓到路徑沒有中文、沒有空格的資料夾，例如 D:\GPT-SoVITS。
  3. 先試跑一次：雙擊資料夾裡的 go-webui.bat，能打開 GPT-SoVITS 的網頁介面就代表安裝成功。確認後關掉它。

Mac 沒有 NVIDIA 顯示卡，可以使用但生成較慢。以下指令都在「終端機」App 裡執行，每段貼上後按 Enter。

  1. 安裝 Homebrew（已安裝可跳過）：依照 brew.sh ↗ 的指令安裝。接著安裝 FFmpeg： 
    brew install ffmpeg
  2. 安裝 Miniconda（已安裝可跳過）：到 Miniconda 下載頁 ↗ 選 macOS Apple Silicon 版本安裝，裝完重新打開終端機。
  3. 下載 GPT-SoVITS： 
    cd ~
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
  4. 建立環境並安裝（會自動下載模型，需要一段時間）： 
    conda create -n GPTSoVits python=3.10 -y
conda activate GPTSoVits
bash install.sh --device MPS --source HF
    如果安裝 MPS 版本失敗，可以把 MPS 改成 CPU 再試一次。

步驟二：放入 VoiceSprite 連接檔

下載以下兩個檔案，放進 GPT-SoVITS 資料夾裡有 api_v2.py 的那一層。

⬇ voicesprite-bridge.py（橋接程式，兩種系統都要） ⬇ start-gptsovits-windows.bat（Windows 啟動檔） ⬇ start-gptsovits-mac.command（Mac 啟動檔）

Chrome 下載 .bat 或 .command 時可能提醒「這類檔案可能有害」，請選「保留」。這兩個檔案只是啟動 GPT-SoVITS 與橋接程式，內容可以用記事本打開確認。

步驟三：啟動

雙擊 start-gptsovits-windows.bat。黑色視窗出現「VoiceSprite 橋接程式」與「網站連線位址」字樣就代表啟動了。第一次載入模型需要等一下。

打開終端機，執行：

cd ~/GPT-SoVITS
bash start-gptsovits-mac.command

出現「VoiceSprite 橋接程式」與「網站連線位址」字樣就代表啟動了。第一次載入模型需要等一下。

要關閉時，直接關掉那個視窗（或按 Ctrl + C），GPT-SoVITS 和橋接程式會一起關閉。重新開機後不會自動啟動，下次使用前再執行一次即可。

步驟四：測試連線

  • 橋接程式
  • GPT-SoVITS
  • 用你的聲線生成一句

完成！到文字轉語音頁使用 →

Chrome 第一次連線時可能詢問「允許這個網站存取本機網路上的裝置」，請按允許。

之後每次使用

  1. 直播或錄音前，先啟動 GPT-SoVITS（步驟三）。
  2. 到「文字轉語音」頁，語音引擎選「本地開源引擎：GPT-SoVITS」，選好聲線特徵檔就能播放、下載 WAV、生成直播台詞板。
  3. 用完關掉視窗即可。

常見問題

測試連線顯示「連不到橋接程式」
  • 確認啟動檔的視窗還開著，而且有出現「網站連線位址」。
  • Chrome 詢問存取本機網路時要按允許；不小心拒絕的話，點網址列左邊的圖示重新允許。
  • 請用 Chrome 或 Edge，Safari 可能會擋下網站連到本機。
  • 如果 9881 被其他程式占用，可以用 python voicesprite-bridge.py --port 9882 啟動，並把上面的網址改成 http://127.0.0.1:9882。
橋接程式已啟動，但連不到 GPT-SoVITS
  • GPT-SoVITS 第一次載入模型需要 1～2 分鐘，等視窗不再跑新訊息後再測試一次。
  • 如果視窗出現紅色錯誤訊息，通常是安裝不完整：Windows 請重新解壓整合包；Mac 請重新執行步驟一的 install.sh。
生成失敗，出現「參考音頻在 3～10 秒範圍外」

網站會自動把太短的參考錄音補到 3 秒以上。如果仍然出現，請到「錄製聲紋」重錄一次，每句用正常語速完整唸完。

想讓聲音更像自己

GPT-SoVITS 可以用 1 分鐘以上的錄音微調模型，相似度會大幅提升。請參考 官方說明 ↗ 的訓練教學，訓練完成後在 GPT_SoVITS/configs/tts_infer.yaml 指定你的模型。

可以開機就自動啟動嗎？

可以，但不建議：GPT-SoVITS 開著會一直占用顯示卡記憶體與系統資源。真的需要的話，Windows 可把啟動檔的捷徑放進「啟動」資料夾（按 Win + R 輸入 shell:startup）。

安全嗎？

橋接程式只接受同一台電腦的連線，而且只允許 VoiceSprite 網站使用，其他網站會被拒絕。參考錄音只會暫存在電腦的暫存資料夾。

可以用在營利直播嗎？

GPT-SoVITS 程式採用 MIT 授權。預訓練模型與你使用的聲音的授權，請自行確認；請只使用本人或已取得同意者的聲音。
